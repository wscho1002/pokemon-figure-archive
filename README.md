# 포켓몬 피규어 아카이브

개인 소장용 포켓몬 피규어를 촬영하고, 포켓몬별로 중복 피규어·구입 정보·대표 썸네일을 기록하는 모바일 우선 PWA입니다.

## 현재 구현된 기능

- PokeAPI 공개 데이터에서 전체 포켓몬 한국어 이름·세대 불러오기
- 포켓몬 이미지/이름 기반 도감 목록
- 이름·영문명·도감 번호 검색
- 보유/미보유, 세대, 최근 등록, 보유 개수 필터
- 웹앱 내부 후면 카메라 촬영
- 기본 카메라 파일 입력 대체 수단
- 촬영 즉시 최대 1440px WebP/JPEG로 압축
- 360px 썸네일 별도 생성
- 원본 사진을 사진 앱이나 서버에 저장하지 않음
- IndexedDB에 사진 Blob과 피규어 정보 저장
- 같은 포켓몬의 피규어 여러 개 등록
- 대표 썸네일 지정
- 폼, 제조사, 시리즈, 상품 번호, 가격, 출처, 구입일, 상태, 보관 위치, 메모
- 사진 포함 JSON 백업/복원
- 저장공간 사용량 표시 및 영구 저장 요청
- 홈 화면 설치와 오프라인 앱 셸

## GitHub Pages 배포

1. 이 폴더 안의 파일 전체를 GitHub 저장소 최상위에 업로드합니다.
2. 저장소의 `Settings` → `Pages`로 이동합니다.
3. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/ (root)`를 선택하고 저장합니다.
5. 표시되는 Pages 주소로 접속합니다.
6. 아이폰 Safari 공유 버튼 → `홈 화면에 추가`를 누릅니다.

카메라는 HTTPS 환경에서 사용해야 하므로 GitHub Pages 주소에서 시험하세요. 로컬 파일을 직접 열면 카메라와 서비스 워커가 작동하지 않습니다.

## 데이터 저장 위치

- 포켓몬 기본 목록: PokeAPI CSV를 최초 1회 내려받아 IndexedDB에 캐시
- 피규어 기록과 사진: 현재 브라우저의 IndexedDB
- 외부 서버 업로드: 없음
- 사진 앱 자동 저장: 없음

브라우저 사이트 데이터 삭제, 기기 초기화, 주소 변경 시 기록이 사라질 수 있습니다. 설정에서 사진 포함 백업을 주기적으로 내보내세요.

## 폼 처리

1차 버전에서는 각 피규어 기록에 `모습·폼`을 자유롭게 입력합니다. 다음 버전에서 포켓몬 종·공식 폼·상품 자세/색상 변형을 별도 테이블로 나눌 수 있도록 기록 구조를 분리해 두었습니다.

## 외부 데이터

- 포켓몬 이름·세대: PokeAPI 프로젝트 CSV
- 기본 도감 이미지: PokeAPI sprites 저장소의 official-artwork 경로

공개 서비스나 상업 서비스로 전환하기 전에는 이미지 및 상표 사용 조건을 별도로 검토해야 합니다.

## 2차 대시보드 업데이트

- 전국도감 완성률 퍼센트 및 애니메이션 진행 바
- 보유 종 / 전체 종 수 표시와 미보유 바로가기
- 세대별 완성률 바 및 탭 필터 연결
- 보유 종, 총 피규어, 중복 피규어, 이번 달 획득 요약
- 최근 획득 피규어 가로 목록
- 새로운 포켓몬 종을 처음 등록할 때 도감 등록 완료 연출


## 3차 제조사·시리즈 도감 업데이트

- 제조사별 보유 피규어 수와 시리즈 수 자동 집계
- 제조사 카드를 눌러 전체 포켓몬 도감 즉시 필터
- 시리즈별 실물 개수와 중복 제외 상품 종류 수 계산
- 사용자가 시리즈 전체 목표 상품 수를 직접 설정
- 목표 대비 완성률 퍼센트와 진행 바 표시
- 제조사·시리즈 전용 검색 필터 추가
- 기존 제조사·시리즈 입력값을 자동완성 후보로 제공
- 시리즈 목표를 백업 파일에 포함하고 이전 버전 백업도 불러오기 가능

시리즈의 중복 제외 기준은 상품 번호를 우선 사용합니다. 상품 번호가 없으면 피규어 이름, 둘 다 없으면 포켓몬과 모습 조합을 기준으로 계산합니다.

## 4차 모습 도감·사진 편집 업데이트

- 포켓몬 상세 화면에서 공식 폼·리전폼·메가진화·거다이맥스·성별 차이를 자동으로 불러와 카드로 표시
- 공식 모습별 보유 개수, 미보유 상태, 모습 도감 완성률과 진행 바 표시
- 모습 카드를 눌러 해당 폼의 피규어 기록만 필터링
- 피규어 등록 화면에서 공식 모습을 이미지 카드로 선택
- 기존 자유 입력 폼 기록을 이름 기준으로 공식 폼과 자동 연결
- 특별 의상, 투명판, 한정 색상 등 사용자 정의 폼 유지
- 촬영·사진 선택 직후 전용 사진 편집기 실행
- 사진 드래그 이동, 핀치 확대·축소, 확대 슬라이더 지원
- 왼쪽·오른쪽 90도 회전
- 1:1, 4:5, 4:3, 원본 비율 자르기
- 기존에 등록한 사진도 다시 편집 가능
- 편집 결과만 최대 1440px로 압축하고 360px 썸네일을 별도 생성

공식 폼 정보는 포켓몬 상세 화면을 처음 열 때 PokéAPI에서 가져온 뒤 기기에 캐시합니다. 연결에 실패하면 기본 모습만 표시하며 기존 피규어 기록은 그대로 사용할 수 있습니다.

- 일반 화면의 더블탭 및 핀치 페이지 확대를 차단했습니다.
- 사진 편집기의 드래그와 핀치 확대는 계속 사용할 수 있습니다.
