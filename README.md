# 포켓몬 피규어 아카이브 v5.2 MAX

v5.1의 로컬 도감·폼 도감·사진 편집·Supabase 친구 기능을 유지하면서 모바일 사용성과 온라인 기능을 크게 확장한 버전입니다.

## 주요 추가 기능

### 모바일·메인 화면
- 하단 고정 메뉴: 홈 / 도감 / 친구 / 설정
- 친구 요청 숫자 배지와 동기화 대기 표시
- 우측 하단 빠른 등록 버튼
- 최근 등록 포켓몬 우선 빠른 검색
- 세대별 완성률·최근 획득·제조사 도감 모두 접기/펼치기
- 대시보드 모두 접기·모두 펼치기
- 대시보드 섹션 표시 여부와 순서 변경
- 접힌 섹션에도 요약 정보 표시
- 다크 / 라이트 / 기기 설정 테마
- 입력창·버튼·메뉴의 명암 대비 보완

### 클라우드 동기화
- 로컬 기록 수 / 클라우드 기록 수 / 업로드 대기 수 표시
- 마지막 동기화 시간 표시
- 업로드 진행 막대
- 로컬·클라우드 상태 비교
- 로컬만 존재, 클라우드만 존재, 수정 시각 차이 표시
- 자동 동기화
- Wi-Fi에서만 사진 업로드 옵션
- 클라우드 공개 기록 JSON 내보내기
- 모든 기기 로그아웃
- 클라우드 공개 기록과 썸네일만 삭제

### 친구 기능
- 친구 카드를 도감 보기 / 비교하기 / 삭제로 구분
- 친구 공개 도감 열람
- 친구 도감에서 포켓몬·상품 검색
- 제조사 필터
- 공개 썸네일 표시
- 비교 화면에서 나만 / 친구만 / 공통 / 둘 다 미보유 분류
- 비교 검색과 세대 필터
- 친구 코드 복사·공유
- 친구 코드 QR 표시
- 지원 브라우저에서 QR 사진 인식
- 현재 도감 현황을 이미지 카드로 만들어 공유

## 기존 사용자 업데이트

`pokemon-figure-archive-v5.2-update.zip`의 파일을 GitHub 저장소 최상단에 덮어씁니다.

중요:
- 기존 `supabase-config.js`는 삭제하거나 교체하지 마세요.
- v5.2 업데이트 ZIP에는 `supabase-config.js`가 포함되어 있지 않습니다.
- 새 파일 `enhancements.js`도 반드시 업로드해야 합니다.
- 추가 SQL 실행은 필요하지 않습니다. v5.1에서 사용한 Supabase 스키마를 그대로 사용합니다.

업로드 후 GitHub Pages 배포가 완료되면 Safari와 홈 화면 앱을 완전히 종료했다가 다시 실행하세요.

## 브라우저별 제한

- QR 사진 인식은 `BarcodeDetector`를 지원하는 브라우저에서만 작동합니다. 미지원 시 친구 코드를 직접 입력하면 됩니다.
- Wi-Fi 여부 감지는 브라우저가 네트워크 연결 정보를 제공할 때만 엄격히 적용됩니다. 정보를 제공하지 않는 iOS 환경에서는 자동 동기화를 막지 않습니다.
- 자동 동기화는 현재 변경분만 전송하는 방식이 아니라 전체 공개 도감을 안전하게 다시 맞추는 방식입니다. 피규어가 매우 많다면 수동 동기화를 권장합니다.
- QR 이미지는 외부 QR 생성 서비스를 통해 표시되므로 인터넷 연결이 필요합니다.

## 서버에 올라가지 않는 정보

- 가격
- 구입처
- 보관 위치
- 개인 메모
- 고화질 원본 사진

서버에는 친구 비교에 필요한 기본 정보와 공개용 작은 썸네일만 저장됩니다.
