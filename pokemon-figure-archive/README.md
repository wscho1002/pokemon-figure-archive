# 포켓몬 피규어 아카이브

개인 소장용 포켓몬 피규어를 촬영하고, 포켓몬별로 중복 피규어·구입 정보·대표 썸네일을 기록하는 모바일 우선 PWA입니다.

## 현재 구현된 기능

- PokeAPI 공개 데이터에서 전체 포켓몬 한국어 이름·세대 불러오기
- 포켓몬 이미지/이름 기반 도감 목록
- 이름·영문명·도감 번호 검색
- 보유/미보유, 세대, 최근 등록, 보유 개수 필터
- 웹앱 내부 후면 카메라 촬영
- 기본 카메라 파일 입력 대체 수단
- 촬영 즉시 최대 1440px WebP/JPEG로 압축
- 360px 썸네일 별도 생성
- 원본 사진을 사진 앱이나 서버에 저장하지 않음
- IndexedDB에 사진 Blob과 피규어 정보 저장
- 같은 포켓몬의 피규어 여러 개 등록
- 대표 썸네일 지정
- 폼, 제조사, 시리즈, 상품 번호, 가격, 출처, 구입일, 상태, 보관 위치, 메모
- 사진 포함 JSON 백업/복원
- 저장공간 사용량 표시 및 영구 저장 요청
- 홈 화면 설치와 오프라인 앱 셸

## GitHub Pages 배포

1. 이 폴더 안의 파일 전체를 GitHub 저장소 최상위에 업로드합니다.
2. 저장소의 `Settings` → `Pages`로 이동합니다.
3. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/ (root)`를 선택하고 저장합니다.
5. 표시되는 Pages 주소로 접속합니다.
6. 아이폰 Safari 공유 버튼 → `홈 화면에 추가`를 누릅니다.

카메라는 HTTPS 환경에서 사용해야 하므로 GitHub Pages 주소에서 시험하세요. 로컬 파일을 직접 열면 카메라와 서비스 워커가 작동하지 않습니다.

## 데이터 저장 위치

- 포켓몬 기본 목록: PokeAPI CSV를 최초 1회 내려받아 IndexedDB에 캐시
- 피규어 기록과 사진: 현재 브라우저의 IndexedDB
- 외부 서버 업로드: 없음
- 사진 앱 자동 저장: 없음

브라우저 사이트 데이터 삭제, 기기 초기화, 주소 변경 시 기록이 사라질 수 있습니다. 설정에서 사진 포함 백업을 주기적으로 내보내세요.

## 폼 처리

1차 버전에서는 각 피규어 기록에 `모습·폼`을 자유롭게 입력합니다. 다음 버전에서 포켓몬 종·공식 폼·상품 자세/색상 변형을 별도 테이블로 나눌 수 있도록 기록 구조를 분리해 두었습니다.

## 외부 데이터

- 포켓몬 이름·세대: PokeAPI 프로젝트 CSV
- 기본 도감 이미지: PokeAPI sprites 저장소의 official-artwork 경로

공개 서비스나 상업 서비스로 전환하기 전에는 이미지 및 상표 사용 조건을 별도로 검토해야 합니다.
